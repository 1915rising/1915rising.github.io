Featured: fileprobe

13 Languages · Tool

One spec, thirteen implementations

fileprobe is a tiny stdin byte-stats tool — bytes, lines, words, and an FNV-1a hash — specified once and implemented independently in all 13 languages above. A shared test corpus runs every implementation against the same inputs: all 13 outputs are verified byte-identical. It is the cross-check habit, turned into a repository.
