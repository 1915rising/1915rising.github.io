REAL-TIME STRATEGY PROJECT

Unity · C# · Deterministic simulation · Crowd rendering

A real-time strategy game built in Unity, engineered simulation-first. The game logic lives in a standalone, deterministic C# simulation core that runs identically inside the engine, in a plain test harness, and in headless self-tests — the renderer is a view onto the sim, never the source of truth. Free-form base building, squad-based infantry, hero units, and large visible armies are the design pillars.

Engineering highlights

  • Deterministic simulation core. Fixed-tick sim with hash-pinned replay tests: the same scripted match produces the identical state hash in the plain .NET harness, inside Unity, and in a second engine's runtime — bit for bit.
  • VAT crowd rendering. Animation is baked to vertex-animation textures and played back in the shader, so hundreds of figures animate with no per-unit skeleton cost. A pooled renderer is the shipping path; an indirect-draw path was investigated, measured, and set aside on evidence.
  • Complete game shell. Main menu, match setup, five-tab settings persisted to JSON, minimap with an alert feed, control groups, and a full cheat-code system — all commands enter the sim as tick-stamped orders, so cheats and replays obey the same determinism rules as normal play.
  • Automated gates. Roslyn compile checks, a scripted test suite, map-solvability gates, and performance gates run before any build is called good.
  • Headless self-test pipeline. The editor itself is driven over a local API to enter play mode, inspect live match state, and capture screenshots — the same pipeline that caught and verified the fix for a renderer bug that left units invisible while the simulation ran perfectly underneath.

Status

The full game loop is complete and playable end to end: menus, setup, economy, production, combat, and win/lose flow. Current work is the art and polish pass — production crowd-tier meshes replacing the placeholder figures, plus order-feedback markers and selection polish.
