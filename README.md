# 1915 Arcade

Free games, built from scratch. No downloads, no sign-ups — just play.

**Play here:** https://1915rising.github.io/

## Playable in the browser

- **Starfall** — a canvas arcade shooter. [Play](https://1915rising.github.io/starfall/) · [Code](https://github.com/1915rising/starfall-js)
- **Snake** — the timeless classic, with a speed ramp. [Play](https://1915rising.github.io/snake/)
- **Breakout** — paddle, ball, 48 bricks. [Play](https://1915rising.github.io/breakout/)
- **Blockfall** — falling-block puzzler. [Play](https://1915rising.github.io/blockfall/)
- **Pong** — vs AI or local 2-player, first to 7. [Play](https://1915rising.github.io/pong/)
- **Minesweeper** — 9×9, 10 mines, first click always safe. [Play](https://1915rising.github.io/minesweeper/)
- **Skyflap** — a one-button flying game. [Play](https://1915rising.github.io/skyflap/)
- **Number Merge** — slide, merge, reach 2048. [Play](https://1915rising.github.io/number-merge/)
- **Sprint** — an endless runner. [Play](https://1915rising.github.io/sprint/)
