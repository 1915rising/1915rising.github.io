# 1915 Arcade

Free games, built from scratch. No downloads, no sign-ups — just play.

**Play here:** https://1915rising.github.io/

## Games

- **Starfall** (JavaScript) — a canvas arcade shooter, playable right in the browser. [Play](https://1915rising.github.io/starfall/) · [Code](https://github.com/1915rising/starfall-js)
- **Minesweeper** (Java) — the classic, in clean object-oriented Java for the terminal. [Code](https://github.com/1915rising/minesweeper-java)
- **Sky Obby** (Luau) — an 8-stage Roblox obstacle course generated entirely by code. [Code](https://github.com/1915rising/sky-obby)
- **Delver** (C#) — a tiny procedurally generated text roguelike. [Code](https://github.com/1915rising/delver-csharp)

Built by [1915rising](https://github.com/1915rising).
